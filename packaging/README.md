# Packaging

Application packaging and deployment scripts.

## Folders

| Folder | Purpose |
| --- | --- |
| `chrome-hide-crash` | Per-user Chrome preferences tweak to clear crash notification state. |
| `deploy-chrome` | PowerShell installer for Google Chrome Enterprise MSI with architecture detection and download fallbacks. |
| `uninstall-apps-script` | PowerShell function for silent application uninstall from Windows uninstall registry keys. |
