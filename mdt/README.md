# MDT

Scripts, tools, and notes for Microsoft Deployment Toolkit.

## Folders

- `export-folders/` : export deployment share folders.
- `oobe-oem-activation/` : OOBE and OEM activation notes.
- `toolkit-installers/` : Microsoft Deployment Toolkit installers.
- `winpe-ultravnc-extra-directory/` : add UltraVNC tools to WinPE through MDT Extra Directory.
