# Windows Custom Machine

Machine-level Windows customization script for a master image.

Blog category: [Windows Master Images](https://blog.wuibaille.fr/category/administration/master/)

## Files

| File | Purpose |
| --- | --- |
| `install.cmd` | Removes selected provisioned Appx packages, runs WinSAT and applies the Start menu layout. |
| `start.bin` | Start menu layout state copied to the default profile. |
