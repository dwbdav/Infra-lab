# Master

Scripts and templates used while building or customizing Windows master images.

## Folders

| Folder | Purpose |
| --- | --- |
| `active-setup-example` | Minimal Active Setup example that runs a per-user screensaver configuration payload. |
| `active-setup-adminstudio` | Active Setup registry template for AdminStudio/MSI per-user repair scenarios. |
| `auto-admin-logon` | PowerShell example for enabling Windows automatic logon registry keys. |
| `reliability-monitor-remote` | Script and packaged executable for displaying Windows Reliability Monitor history remotely. |
| `windows-oem-activation-11` | Activates Windows with the OEM product key embedded in BIOS. |
| `windows-oem-activation-7` | Legacy Windows 7 OEM certificate files. |
| `windows-cleanup` | Windows component and Disk Cleanup automation. |
| `windows-custom-machine` | Machine-level Windows image customization. |
| `windows-custom-user` | Per-user Windows customization through Active Setup. |
| `windows-mui-build` | Windows 11 multilingual image build scripts. |
| `windows-pin-shortcut-start-menu` | VBScript helper for pinning shortcuts to Start. |
| `windows-powercfg` | Power configuration batch script. |
| `windows-script-upgrade` | In-place Windows upgrade batch workflow. |
| `windows-shell-launcher` | Shell Launcher configuration script. |
