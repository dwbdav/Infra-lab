# Intune

Contenu lie a Microsoft Intune : Autopilot, applications, conformite et remediations.

## Dossiers

- `autopilot/` : profils, enrollement et preparation Autopilot.
- `apps/` : packaging, detection rules et deploiement applicatif.
- `compliance/` : politiques de conformite et controles.
- `remediation/` : scripts de detection et remediation proactive.
