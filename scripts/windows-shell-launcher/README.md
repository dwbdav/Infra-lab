# Windows Shell Launcher

PowerShell script for configuring Windows Shell Launcher with a custom shell for a target account.

Blog category: [Windows Master Images](https://blog.infra-lab.fr/category/administration/master/)

## File

| File | Purpose |
| --- | --- |
| `ShellLauncher.ps1` | Checks Shell Launcher licensing, sets the default shell and configures a custom shell for `kiosk_user`. |

## Notes

- Requires a Windows edition that supports Shell Launcher.
- The source user and command path were replaced with generic lab values.
