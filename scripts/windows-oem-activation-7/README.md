# Windows 7 OEM Certificates

OEM certificate files used by legacy Windows 7 activation workflows.

Source article: [Windows 11 OEM Activation](https://blog.wuibaille.fr/2023/05/activation-oem-windows-11/)

## Content

| Folder | Purpose |
| --- | --- |
| `DELL_V2.1_Cert.xrm-ms` | Dell OEM certificate folder from the source package. |
| `HPQOEM_V2.1_Cert.xrm-ms` | HP OEM certificate folder from the source package. |
| `LENOVO_V2.1_Cert.xrm-ms` | Lenovo OEM certificate folder from the source package. |
