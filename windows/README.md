# Windows

Contenu lie a Windows : PowerShell, deploiement, troubleshooting et securite.

## Dossiers

- `powershell/` : scripts et modules PowerShell.
- `deployment/` : deploiement Windows, images et automatisations.
- `deployment/mdt/` : scripts et automatisations Microsoft Deployment Toolkit.
- `troubleshooting/` : diagnostics et resolution d'incidents.
- `security/` : durcissement, controles et configuration securite.
