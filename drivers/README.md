# Bios & Drivers

BIOS configuration scripts, driver download tools and WinPE driver packs.

Blog category: [Bios & Drivers](https://blog.wuibaille.fr/category/administration/drivers/)

## Folders

| Folder | Purpose |
| --- | --- |
| `hp-enable-virtualization` | Enables HP BIOS virtualization settings through WMI. |
| `hp-bios-config-gui` | WPF GUI to audit and apply HP BIOS settings. |
| `dell-drivers-downloader-gui` | GUI downloader for Dell driver packs using Dell DriverPackCatalog. |
| `winpe-touchpad-850g7` | WinPE touchpad driver pack for HP 850 G7 class devices. |
| `winpe-touchpad-850g8` | WinPE touchpad driver pack for HP 850 G8 class devices. |
