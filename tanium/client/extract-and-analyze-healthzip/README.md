# Extract and Analyze Health ZIP

Source article: to be linked when the matching blog post is published or identified.

## Purpose

`Extract-EipGui.ps1` provides a Windows GUI to extract `.eip` or `.zip` health packages, clean the extracted workspace, and search logs or text files for troubleshooting keywords.

## Files

- `Extract-EipGui.ps1` : PowerShell WinForms utility for recursive archive extraction, cleanup, and log keyword search.
