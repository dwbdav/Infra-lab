# Tanium

Contenu lie a Tanium : deploiement, patch management, provisioning, client et environnements on-prem.

## Dossiers

- `deploy/` : packages, procedures et automatisations de deploiement.
- `patch/` : notes et scripts autour du patch management.
- `provision/` : provisioning et preparation des postes.
- `client/` : installation, configuration et diagnostic du client Tanium.
- `on-prem/` : elements specifiques aux environnements Tanium on-prem.
