# Infra

Infrastructure administration scripts.

Blog category: [Infra](https://blog.wuibaille.fr/category/administration/infra-administration/)

## Folders

| Folder | Purpose |
| --- | --- |
| `hyperv-backup-vm` | Exports Hyper-V VMs matching a naming pattern and copies them to a backup share. |
| `hyperv-guest-script-runner` | Runs scripts inside Hyper-V guests from the host. |
